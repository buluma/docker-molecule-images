# Ubuntu 26.04 LTS

Docker image for Ubuntu 26.04 LTS (Resolute Raccoon), designed for testing Ansible roles. The release shipped on April 23, 2026 and receives standard support through May 29, 2031.

## Features

- Systemd enabled for proper service management
- Python 3 and pip for Ansible compatibility
- Docker user preconfigured for testing
- Optimized for Ansible role testing
