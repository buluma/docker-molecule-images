# Fedora 45

Docker image for Fedora 45, designed for testing Ansible roles.

## Overview

Fedora 45 tracks Rawhide and has not yet shipped, featuring the latest open source technologies and tools for developers, creators, and system administrators.

## Features

- Systemd enabled for proper service management
- Python 3 and pip for Ansible compatibility
- Docker user preconfigured for testing
- Optimized for Ansible role testing
